# Chess Game in C++

A console-based chess game implemented in C++ as part of a project with multiple development iterations. The repository contains an earlier prototype and a more complete version of the game logic and interface.

## Overview

This project demonstrates a turn-based chess game built in C++. It includes:

- a simple prototype version in `5th_iteration.cpp`
- a more complete implementation in `7th_iteration.cpp`
- project documentation in `Project report (The chess game).docx`

According to the project notes, the 5th iteration is an earlier version used to explain the logic without full data-structure-based implementation, while the 7th iteration includes the proper interface and implementation.

## Repository Contents

- `5th_iteration.cpp` — earlier version of the chess game logic and concept demonstration
- `7th_iteration.cpp` — final/complete implementation with interface and gameplay logic
- `Project report (The chess game).docx` — project report documenting the design and implementation
- `read me.txt` — short project note explaining the iteration differences
- `LICENSE` — Apache 2.0 license
- `README.md` — project documentation

## Features

- Console-based chess gameplay
- Two-player turn system
- Board representation and move flow
- Piece movement logic (as implemented in the final iteration)
- Iterative project development history for learning and reference

## How to Run

Compile the final version with a C++ compiler:

```bash
g++ 7th_iteration.cpp -o chess_game
./chess_game
```

If you want to run the earlier prototype instead:

```bash
g++ 5th_iteration.cpp -o chess_game_5th
./chess_game_5th
```

## Notes

- The project is a C++ console application, so it is intended to run in a terminal or command-line environment.
- `7th_iteration.cpp` is the recommended version to use for the actual game implementation.
- The report file provides additional design details and project background.
